# .github

Organization-wide default pull request template for EarnUp repositories (`.github/PULL_REQUEST_TEMPLATE.md`). A repository with its own template overrides it.

This repository has to stay public. GitHub applies default community health files, such as this template, only from a public `.github` repository: a private one is not allowed, and internal is supported only for Enterprise Managed Users organizations, which EarnUp is not. See [Creating a default community health file](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).
